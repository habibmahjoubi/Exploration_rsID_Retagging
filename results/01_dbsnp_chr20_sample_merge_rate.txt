Initial sample (biased, not representative) — 2026-08-23
============================================================

Source: https://ftp.ncbi.nlm.nih.gov/snp/latest_release/JSON/refsnp-chr20.json.bz2
Method: HTTP range-fetch (0-30,000,000 bytes out of ~9.0GB), streaming bzip2 decompression
        (the stream truncated at the end of the chunk produces an expected bzip2 error —
        blocks already decoded before the cut remain valid).

WARNING — selection bias: the dbSNP file is sorted by increasing refsnp_id
(rsID number), NOT by genomic position. This first sample therefore only contains the
oldest rsIDs (rs754 to ~rs20000), i.e. variants submitted very early (~2000-2001),
disproportionately well-studied. This is NOT a merge rate representative of a
modern NGS genome — see results/02 for the relevant figure (cross-referenced with real
GIAB HG002 variants).
